# ha_creator

Программа для проектирования умного дома под Home Assistant. Конвейер:

1. схема имеющихся коммуникаций объекта;
2. схема автоматизации (датчики, исполнители, сценарии);
3. подбор комплектующих, доступных в России, с ценами в рублях;
4. смета оборудования, материалов и работ;
5. экспорт готового проекта под Home Assistant (YAML, packages).

Эталонный объект — дача: на ней проверяется каждый этап.

## Состояние

Сделаны каркас проекта, модель данных, эталонная дача, каталоги v0 и редактор цен.
Расчёт сметы, генератор YAML и редакторы схем — следующие этапы.

## Редактор цен

Открывается по `npm run dev`. В нём две вкладки: комплектующие и работы.

- Цена, статус и источник правятся прямо в таблице. Изменённая цена получает статус «проверено» и сегодняшнюю дату.
- Есть поиск, фильтр по категории и по состоянию: ориентир, проверено, старше 60 дней, изменено мной.
- **Импорт из Excel** принимает `.xlsx` и `.csv`. Колонки с артикулом, названием, ценой и источником определяются
  по заголовкам, и их можно поправить вручную. Позиции ищутся по артикулу, а если его нет — по точному названию.
  Перед применением показывается, какие цены изменятся; изменение больше чем в полтора раза помечается.
  Строки, которых нет в каталоге, не загружаются. Старый формат `.xls` не поддерживается.
- **Скачать Excel** выгружает текущую вкладку. Этот файл можно поправить в Excel и загрузить обратно.
- **Скачать YAML** выгружает каталог в формате репозитория: файл кладётся в папку `catalog` вместо прежнего.
- Правки хранятся в браузере (localStorage), сервера у приложения нет.

## Структура

| Путь | Что там |
| --- | --- |
| `packages/core` | Ядро без интерфейса: модель данных (Zod), проверка связности проекта, разбор прайс-листов |
| `apps/web` | Веб-приложение (React + Vite). Сейчас в нём редактор цен |
| `catalog/devices.yaml` | Каталог комплектующих |
| `catalog/works.yaml` | Справочник расценок на работы |
| `catalog/scenarios.yaml` | Каталог типовых сценариев автоматизации |
| `examples/dacha.json` | Эталонный проект дачи |

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm test          # тесты ядра
npm run typecheck # проверка типов
npm run dev       # веб-приложение на http://localhost:5173
```

## Что важно знать о данных

- **Цены в каталогах — ориентиры.** У каждой позиции стоит `priceStatus: estimate`: цены не сверены с магазинами.
  Перед расчётом настоящей сметы цену нужно проверить, указать `source`, обновить `priceDate`
  и поставить `priceStatus: verified`.
- **Дача описана на допущениях:** два этажа около 120 м², электрокотёл, скважина, септик, интернет через 4G,
  сезонное проживание. Когда появится реальный план, `examples/dacha.json` нужно поправить.
- **Идентификаторы** (`id`) пишутся латиницей в нижнем регистре: из них будут строиться `entity_id` в Home Assistant.
